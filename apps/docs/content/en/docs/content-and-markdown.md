# Content & Markdown

Parsing and syntax highlighting happen once at build time. The browser receives HTML strings plus a table of contents, so no Markdown parser ships to the client.

## Frontmatter

```md
---
title: Getting Started
description: One sentence used in cards and search.
date: 2026-01-15
tags: [guide, tanstack]
order: 1
draft: false
type: docs
---

# Getting Started
```

| Field | Type | Effect |
| --- | --- | --- |
| `title` | `string` | Page title; falls back to the first heading or filename |
| `description` | `string` | Meta description, card text and search snippet |
| `date` | `string` | Sort key for blog posts |
| `tags` | `string[]` or comma-separated string | Blog tag filter |
| `order` | `number` | Sidebar ordering within a section |
| `draft` | `boolean` | Excludes the page from lists and search |
| `type` | `page \| blog \| docs \| component` | Overrides directory inference |

Extra fields are preserved in `entry.meta` for custom components.

Hovering the `#` anchor shows a copy-link tooltip; clicking copies the full heading URL instead of only moving the hash.

## Headings and anchors

Headings get deterministic, duplicate-safe IDs. They are collected into `entry.headings` (levels 2 and 3) and rendered into the right-hand table of contents. Hover a heading in this page to see its anchor.

## Callouts

The docs preset supports GitHub-style alerts:

```md
> [!TIP] Cache the parsed document
> Rendering an AST avoids parsing the same article twice.
```

> [!TIP] Cache the parsed document
> Rendering an AST avoids parsing the same article twice.

Supported kinds: `NOTE`, `TIP`, `IMPORTANT`, `WARNING`, `CAUTION`.

## Code blocks

Fence metadata is parsed even without a highlighter. `file`, `framework` and highlighted-line ranges become `data-*` attributes on the rendered `<pre>`:

````md
```tsx file="app.tsx" framework="react" {2,4-6}
const one = 1
const next = one + 1
```
````

TanStack Highlight tokenizes the inner code at build time and emits escaped markup. Light and dark token themes are generated by `createThemeCss`.

## Component comments

Single components and block components are expressed as HTML comments, so the Markdown stays valid:

```md
<!-- ::separator tone="subtle" -->

<!-- ::start:tabs -->
## React
React content
## Solid
Solid content
<!-- ::end:tabs -->
```

The preset transforms `tabs` variants (`files`, `package-manager`, `bundler`) into custom elements with `data-*` metadata. Your application decides how to render them.

## Security

Raw HTML is escaped unless explicitly enabled (this framework never enables it), and executable URL protocols such as `javascript:` are removed from links and images. Highlighter output is trusted markup produced only by the TanStack Highlight adapter.
