# 用九个颜色设计主题市场

主题市场成败在于契约。太小则主题无法表达自己；太大则每个主题都变成 UI 的 fork。我们最终选择了九个颜色令牌、三套字体栈和一个圆角三元组。

## 为什么是九个颜色

文档 UI 的词汇有限：页面、表面、次级表面、正文、次要文字、边框、强调色、强调色文字、代码文字。分配完之后，每个组件都能在无主题感知的情况下完成样式。

配色更丰富的配方（如 Bloomberg 的涨跌色）可以通过主题的 `css` 字段补充，而无需改变契约。

## 手工调校与派生

六套旗舰配方提供了手工编写的双模式配色，其余配方使用原生配色并生成互补模式。每套主题都有独立预览页与截图。

## 插件，而非 fork

旗舰主题同时作为独立包发布：`@tanstack-blog/theme-linear`、`theme-muji`、`theme-stripe`，返回 `{ name, theme }`。新增主题只需安装一个包。

## 我们规避的陷阱

没有做主题编辑器——市场更需要明确、有观点的预设，而不是取色器。需要完全控制的开发者可以用二十行代码写一个主题对象。
