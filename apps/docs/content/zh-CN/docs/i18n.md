# 国际化

## 声明语言

```ts
i18n: {
  defaultLocale: 'en',
  locales: [
    { code: 'en', label: 'English', dir: 'ltr' },
    { code: 'zh-CN', label: '简体中文', dir: 'ltr' },
    { code: 'ar', label: 'العربية', dir: 'rtl' },
  ],
}
```

默认语言使用 `/docs`，其他语言使用 `/zh-CN/docs`。`alwaysPrefixLocale: true` 可为所有语言加前缀。

## 内容目录

按语言代码镜像目录。非语言代码的首段视为默认语言。

## 字典

内置英文与简体中文，可扩展：

```ts
registerDictionary('fr', { 'nav.docs': 'Documentation', 'toc.title': 'Sur cette page' })
```

`createTranslator(locale)` 依次回退到英文与键名。

## 语言切换

顶部下拉调用 `switchLocaleRoute(config, pathname, locale)`，保留当前页面。

## RTL

设置 `dir: 'rtl'` 后侧边栏与目录自动翻转。
